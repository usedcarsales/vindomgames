# Vindom Games

Landing page for Vindom Games — trading cards, collectibles, and related merchandise.

## Live Site
https://vindomgames.com → GitHub Pages

## Stack
- Static HTML/CSS (no framework, no build step)
- Hosted on GitHub Pages
- DNS via Namecheap → CNAME to `usedcarsales.github.io`

## DNS Setup (Namecheap)
To point `vindomgames.com` to GitHub Pages:
1. Add CNAME record: `www` → `usedcarsales.github.io`
2. Add A records for apex domain:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
3. In repo Settings → Pages → Custom domain: `vindomgames.com`
4. Enable "Enforce HTTPS"
